# Exec Scope — DART 임원 인텔리전스 (부서 내부용)

DART 정기보고서 임원현황을 기반으로 금융권 전현직 임원을 통합 조회·필터링하는 툴입니다.
Cloudflare Pages + Functions로 배포하며, DART API 키는 서버 환경변수로 숨겨집니다.

## 폴더 구조

```
.
├── index.html               # 메인 화면 (단일 파일, vanilla JS)
├── corp_index.json          # 전체 공시기업 인덱스 (스크립트로 생성, 배포 시 필수)
├── functions/
│   └── api/
│       └── dart.js          # DART 프록시 (키 은닉 + 비밀번호 검증)
└── scripts/
    └── build_corp_index.py  # corp_index.json 생성 스크립트
```

## 배포 절차 (약 15분)

### 1. corp_index.json 생성 (로컬에서 1회)

```bash
python3 scripts/build_corp_index.py 발급받은_DART_API_키
```

→ 프로젝트 루트에 `corp_index.json` 생성 확인 (약 100,000개사, 수 MB).
분기에 한 번 정도 재실행해 신규 공시기업·사명 변경을 반영하면 좋습니다.
(파이썬 표준 라이브러리만 사용하므로 별도 설치가 필요 없습니다.)

### 2. Cloudflare Pages 배포

1. https://dash.cloudflare.com → Workers & Pages → Create → Pages
2. **권장: GitHub 저장소 연동.** Git 연동 배포는 `functions/` 폴더를 자동 인식하므로 가장 편합니다.
   (빌드 설정: 빌드 명령 없음, 출력 디렉토리 `/`)
   - Direct Upload 를 쓰는 경우 functions 가 인식되지 않을 수 있으므로
     `wrangler pages deploy .` CLI 사용을 권장합니다.
3. 배포 후 `프로젝트명.pages.dev` 주소 확인

### 3. 환경변수 설정 (필수)

Pages 프로젝트 → Settings → Environment variables → Production에 추가:

| 변수명 | 값 |
|---|---|
| `DART_API_KEY` | DART OpenAPI 인증키 |
| `APP_PASSWORD` | 부서 공용 비밀번호 (직접 정하기) |

설정 후 **재배포(Retry deployment)** 해야 적용됩니다.

### 4. 접속 확인

`https://프로젝트명.pages.dev` → 비밀번호 입력 → 프리셋 클릭 → 조회 실행.

## 주요 기능

- **금융권 프리셋**: 은행 / 증권 / 생명보험 / 손해보험 / 자산운용 / 저축은행 원클릭 추가
- **전체 기업 검색**: 공시기업 전체 대상 자동완성 (분야 무관 확장 가능)
- **그룹 저장**: 선택 기업을 그룹으로 저장(브라우저 저장) + JSON 내보내기/가져오기로 부서원 간 공유
- **전현직 통합**: 과거 사업보고서 순회 → 최신 보고서에 없는 인물은 "퇴임 추정" 분류
- **임기만료 시그널**: 만료 6개월 이내 재직 임원 자동 하이라이트
- **필터**: 포함/제외 키워드, 사외이사·감사 기본 제외, 출생연도, 등기/상근, 자산총계 규모
- **뉴스 링크**: 인물별 네이버·구글 뉴스 검색 원클릭
- **CSV 다운로드**: Excel 호환(BOM 포함)

## 운영 시 유의사항

- **API 한도**: DART 키는 일일 호출 한도(2만 건)가 있습니다. 조회 결과는 브라우저에 캐싱되어
  같은 조회는 API를 다시 타지 않지만, 처음 넓은 범위를 조회할 때는 호출이 많습니다.
  한도 초과 시 화면에 안내가 뜨며, 다음 날 다시 조회하면 됩니다.
- **데이터 시점**: 정기보고서 기준이므로 최신 인사가 수개월 지연될 수 있습니다.
  "최신 분기·반기보고서 포함" 옵션(기본 켜짐)이 이 공백을 일부 보완합니다.
- **자산운용사 등 일부 비상장사**: 정기보고서 미제출사는 조회 결과가 비어 있을 수 있습니다.
- **비밀번호**: 서버(Functions)에서 검증하므로 HTML 소스에 노출되지 않습니다.
  더 강한 통제가 필요하면 Cloudflare Access(50명 무료)로 회사 이메일 인증을 추가하세요.
- 본 툴의 데이터는 공시정보이나 인물 정보를 포함하므로 **외부 공유 금지** 원칙을 유지하세요.
